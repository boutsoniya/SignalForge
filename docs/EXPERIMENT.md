# Experiment Plan

## Hypothesis
If customer evidence is organized into transparent opportunity scores, PMs will prioritize faster without lowering decision confidence.

## Test
Recruit 5–8 participants with basic product/project experience. Give each a fixed set of feedback signals and ask them to select the top three opportunities.

### Control
Participants use a spreadsheet or notes.

### Treatment
Participants use SignalForge.

## Primary metric
Median time to produce a ranked top-three list.

## Guardrails
- Reviewer confidence
- Evidence coverage per decision
- Number of contradictory signals ignored

## Success threshold
The treatment should reduce median decision time by at least 30% while maintaining or improving confidence.

## Learning questions
1. Which score inputs do users distrust?
2. Does RICE help or create false precision?
3. Do users inspect evidence before accepting a recommendation?
4. Which part of the workflow creates the most cognitive load?
